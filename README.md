# 💰 Interactive Web Budget Tracker

A modern, responsive web application for tracking personal finances with beautiful visual charts and comprehensive budget management features.

## ✨ Features

### 📊 Dashboard Overview
- **Real-time Summary Cards**: View total income, expenses, and net balance at a glance
- **Visual Charts**: Interactive pie chart for expense categories and line chart for monthly trends
- **Current Date Display**: Always know when you're viewing your budget

### 💵 Transaction Management
- **Add Income**: Record salary, freelance work, investments, and other income sources
- **Add Expenses**: Track spending with categorized expenses (Food, Transportation, Entertainment, etc.)
- **Edit & Delete**: Manage existing transactions with easy-to-use controls
- **Automatic Calculations**: Real-time updates to totals and balances

### 🎯 Budget Goals
- **Monthly Budget Setting**: Set spending goals and track progress
- **Progress Visualization**: Color-coded progress bar showing budget status
- **Budget Alerts**: Visual indicators when approaching or exceeding budget limits

### 🔍 Advanced Filtering
- **Transaction Type**: Filter by income only, expenses only, or view all
- **Time Periods**: View transactions for this month, last month, this year, or all time
- **Real-time Updates**: Filters update instantly without page reload

### 📱 Responsive Design
- **Mobile-First**: Optimized for phones, tablets, and desktop
- **Modern UI**: Beautiful gradients, animations, and hover effects
- **Accessibility**: Keyboard navigation and screen reader friendly

### 💾 Data Persistence
- **Local Storage**: All data saved automatically in your browser
- **No Server Required**: Works completely offline
- **Sample Data**: Includes demo transactions for first-time users

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No installation required!

### Quick Start
1. **Clone or Download** the repository
2. **Open `index.html`** in your web browser
3. **Start Budgeting!** Add your income and expenses

### File Structure
```

```

## 💡 Usage Examples

### Adding Income
1. Navigate to the "Add Income" form
2. Enter description (e.g., "Monthly Salary")
3. Enter amount (e.g., 3500)
4. Select date
5. Click "Add Income"

### Setting Budget Goals
1. Enter your monthly budget limit
2. Click "Set Goal"
3. Watch the progress bar update automatically
4. Monitor spending throughout the month

### Viewing Reports
- **Expense Breakdown**: Check the pie chart to see spending by category
- **Monthly Trends**: Use the line chart to track income vs expenses over time
- **Filter Data**: Use dropdown menus to focus on specific time periods or transaction types
